# ToxiUI v7.6.2 - 2026-11-09

**Full Changelog**: <https://github.com/Toxicom/toxiui/compare/v7.6.1...v7.6.2>

- Gradient Mode: Nameplates

- Gradient Mode: Follower dungeon NPCs now get their class colors right away instead of after a `/reload`

## 📘 Documentation

- Random tips: Added a lot of new tips and refreshed outdated ones
  - Some tips are only shown on clients where the feature exists
- Increase minimum required **ElvUI** version to `16.01`
